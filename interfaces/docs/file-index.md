# Interface File Index

This index covers every non-generated file under `interfaces/` that participates in the runtime or explains how to use it.

## Runtime Files

| File                                                     | Purpose                                                                                                                                                                                        | Key parameters / knobs                                                                                                                                                                                                                                                      |
| -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `interfaces/docker-compose.interface.yml`                | Main compose surface for the interface layer, included by the root compose entrypoint.                                                                                                         | `LITELLM_*`, `INTERFACE_*`, `VLLM_RUNTIME_*`, `VLLM_QWEN_3_6_27B_IMAGE`, `VLLM_QWEN_3_6_27B_CONTAINER_NAME`, `VLLM_QWEN_3_6_27B_CUDA_VISIBLE_DEVICES`, `VLLM_QWEN_3_6_35B_A3B_IMAGE`, `VLLM_QWEN_3_6_35B_A3B_CONTAINER_NAME`, `VLLM_QWEN_3_6_35B_A3B_CUDA_VISIBLE_DEVICES`. |
| `interfaces/config/litellm/litellm-config.yaml`          | LiteLLM root include file and global runtime settings. Provider model catalogs now live under `interfaces/config/litellm/providers/`.                                                          | `DATABASE_URL`, retry policy, logging flags, Anthropic-to-chat bridging, callbacks, and the provider include list.                                                                                                                                                          |
| `interfaces/config/litellm/providers/azure-foundry.yaml` | Azure-backed model catalog entries published under the consistent `openai/...` and `anthropic/...` scheme plus the `claude-opus-4-7` compatibility alias.                                      | `MICROSOFT_FOUNDRY_*`, orchestrator and hosted Azure model definitions.                                                                                                                                                                                                     |
| `interfaces/config/litellm/providers/dgx.yaml`           | DGX-hosted Qwen 3.6 27B entries, consolidated to `SWE` and `Writing`, published under the consistent `openai/...` and `anthropic/...` scheme plus the `claude-sonnet-4-6` compatibility alias. | `QWEN3_6_27B_*`, reasoning flags, and DGX sampling presets.                                                                                                                                                                                                                 |
| `interfaces/config/litellm/providers/nvidia.yaml`        | NVIDIA-hosted catalog entries published under the consistent `openai/...` and `anthropic/...` scheme.                                                                                          | `NVIDIA_*`, DeepSeek V4 Flash, MiniMax M2.7, and Kimi K2.6 definitions.                                                                                                                                                                                                     |
| `interfaces/config/litellm/providers/deepseek.yaml`      | Native DeepSeek provider catalog entries published under the consistent `openai/...` and `anthropic/...` scheme plus the latest Haiku compatibility aliases.                                   | `DEEPSEEK_*`, DeepSeek V4 Flash and V4 Pro definitions.                                                                                                                                                                                                                     |
| `interfaces/llama-mtp.sh`                                | Direct host launcher for the llama.cpp 27B backend.                                                                                                                                            | `LLAMA_QWEN_3_6_27B_*`, especially `*_BINARY_PATH`, `*_GGUF_MODEL_PATH`, `*_SCRIPT_PORT`, context, batch, and speculative-decoding knobs.                                                                                                                                   |
| `interfaces/vllm/qwen3.6-27b-fp8-mtp.sh`                 | Launches the recipe-pinned vLLM 27B FP8 MTP backend inside the compose service.                                                                                                                | Hard-coded recipe flags plus container env supplied by `docker-compose.interface.yml`.                                                                                                                                                                                      |
| `interfaces/vllm/qwen3.6-35b-a3b-fp8-mtp.sh`             | Launches the recipe-pinned vLLM 35B A3B FP8 MTP backend inside the compose service.                                                                                                            | Hard-coded recipe flags plus container env supplied by `docker-compose.interface.yml`.                                                                                                                                                                                      |
| `mods/fix-qwen3-coder-next`                              | Shared pre-launch patch mod copied from `spark-vllm-docker`.                                                                                                                                   | Applies crash/slowness patch logic and Triton allocator workaround before service start.                                                                                                                                                                                    |
| `mods/fix-qwen3.6-chat-template`                         | Shared pre-launch chat-template mod copied from `spark-vllm-docker`.                                                                                                                           | Copies `chat_template.jinja` to `/workspace/fixed_chat_template.jinja` before service start.                                                                                                                                                                                |

## LiteLLM Helper Code

| File                                                          | Purpose                                                                                              | Key parameters / knobs                                                                                                      |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `interfaces/scripts/litellm/litellm_qwen36_sanitizer.py`      | Sanitizes malformed or partial tool-call XML in both streaming and non-streaming Qwen 3.6 responses. | Allowed structural tags, function-name and parameter-name regexes, stream carry length, tool argument allowlist extraction. |
